# BlinkPaste releases

Download the latest BlinkPaste build from
[Releases](https://github.com/chasing-brains/blinkpaste-releases/releases/latest).

BlinkPaste source is maintained in a private repository. This public repository
intentionally contains only release automation, this README, and binary
releases. The automation checks private `main` hourly and skips any source
commit that already has a release.
